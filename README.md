# ClassBridge
**Never Miss What Happened in Class**

A mobile-friendly, local-first student homework and catch-up prototype.

## Included
- Password is hidden by default; the Show/Hide control toggles visibility.
- 29 accounts, including Raj Kumar (`CB14XX`).
- 16 unique subjects: Science, Maths, SST, Music, English Literature, English Grammar, Urdu, Sanskrit, GK, Computer, Hindi Literature, Hindi Grammar, French Language, Language Lab, Game, Art and Craft.
- Full-access accounts can add either Homework or Classwork.
- Starts with an empty work board; no demo tasks are preloaded.
- Search/filter tasks, mark work complete, and generate a catch-up plan.

## Run
Open `index.html` in a browser or upload `index.html`, `manifest.json`, `sw.js`, and `logo.png` to GitHub Pages.

## Data note
This prototype stores work locally in the browser on the current device. It does not sync work between different users/devices and is not a secure server-backed authentication system.
